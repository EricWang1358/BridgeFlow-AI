# 模拟报价样板（#104、#7、#20、#40）

> **全部为虚构样板**，按商砼行业常见做法编写，用来在真实样板到位前演示报价链路。单位、项目、人名、价格与政策数值都要由真实业务方替换或确认。

| 文件 | 相当于业务方要交的 |
| --- | --- |
| `01-客户询价记录.md` | 客户会话 / 询价记录 |
| `02-混凝土供货合同范本.md` | 采购（供货）合同样板 |
| `03-标准报价单模板.xlsx` | 人工标准报价单，每个数字标明原件位置 |
| `04-成本与产能依据.xlsx` | 配合比材料成本、运输泵送制造费用、拌站产能与在手订单、客户回款记录 |
| `05-定价与信用政策.md` | 最低毛利、价格带、信用等级与账期、产能预留、审批与放行责任人 |
| `dictionary.yaml` | 按上述政策写的报价声明（输入、价格带公式、检查、审批人） |
| `extraction.yaml` | 人工核对的抽取记录：每个输入取自哪份原件哪个位置 |
| `expected-quote.md` | 人工手算的标准答案 |

`backend/tests/test_mock_quotation.py` 打开原件核对每条抽取的片段与数值，用 `evaluate_document` 按声明出草稿，与标准答案逐项比对；
并验证付款比例低于下限、产能不足时拒绝出草稿。表格件由 `scripts/make_mock_quotation.py` 生成。

这套样板**不代表**已经实现从原件自动抽取：抽取记录是人工核对的。真实样板到位后，先按它确定抽取规范，再实现抽取。
