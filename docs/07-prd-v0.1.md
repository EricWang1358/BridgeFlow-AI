## 二 产品概述

平台面向每月由生产、物资、财务和市场部门提供的 CSV 或 Excel 数据。系统先识别并修复数据质量问题，再把 SKU、原材料、财务科目和产能耗能等对象映射到统一语义，随后按部门视角生成分析、风险预警、汇总表和审批材料。市场部门还可以在同一数据基础上模拟报价与账期方案。

## 三 用户问题

| 角色 | 当前问题 | 需要完成的工作 |
| --- | --- | --- |
| 数据管理员 | 文件格式、字段名称、日期粒度和缺失值不一致 | 完成月度批量导入，查看修复建议并确认低置信度处理 |
| 生产人员 | 订单、耗能和产能数据分散 | 判断需求趋势、产能充足度和异常消耗 |
| 财务人员 | 项目与科目难以按同一对象关联 | 识别潜亏、账期拉长和坏账风险 |
| 物资人员 | 原材料价格和采购成本缺少联动 | 监测趋势、异常波动及成本影响 |
| 市场人员 | 报价未同时考虑成本、产能和客户条件 | 模拟报价和账期，提交审批而非直接外发 |
| 审批人员 | 结论来源和计算过程难追溯 | 查看证据、差异、风险原因和审批记录 |

## 四 产品目标

1. 建立统一的月度数据入口，使多部门文件可以在同一批次中导入、校验和追溯。
2. 建立跨部门实体与时间口径映射，使同一 SKU、原材料、科目和产能指标可以关联分析。
3. 向不同部门提供基于同一证据的数据结论，并对高风险项目给出可解释的预警。
4. 生成月度、季度和年度 Master Table、汇总看板、风险报告及审批卡片。
5. 让市场人员在成本和产能约束下试算报价，但保留人工审批和最终发送权。

## 五 产品范围

| 范围 | 首版包含 | 首版不包含 |
| --- | --- | --- |
| 数据接入 | CSV、XLSX 月度批量上传；多表并行校验；导入批次管理 | 实时流数据；任意数据库自动发现 |
| 数据处理 | 拼写、格式、错位、缺失、时间序列补全建议和归一化 | 未经确认覆盖原始文件；对关键金额静默填充 |
| 语义对齐 | SKU、原材料、财务科目、产能耗能映射；版本化映射表 | 完全无人审核的实体合并 |
| 分析预警 | 生产、财务、物资、市场四类视图和规则化预警 | 无证据的因果判断；自动执行采购或财务操作 |
| 输出 | Master Table、看板、风险报告、审批卡片和可下载文件 | 直接修改源系统交易记录 |
| 报价模拟 | 价格、成本、产能、账期联动试算和审批 | 自动向客户发送报价；自动承诺交期或信用额度 |

## 六 产品主流程

1. 用户创建月度导入批次，选择部门、月份和文件并上传。
2. Data Sanitizer Agent 解析文件，生成质量报告、修复建议和待确认项。
3. 数据管理员确认关键修复后，系统保存标准化数据和修复日志。
4. Semantic Resolver Agent 根据映射表对齐实体、指标和时间粒度，低置信度结果进入人工映射队列。
5. Multi Role Evaluator Agent 从生产、财务、物资和市场视角计算指标与风险。
6. SOP and Flow Engine 生成 Master Table、看板、风险报告和审批卡片。
7. 市场人员可基于已发布批次启动报价模拟，方案须经授权人员审批后才能导出。

## 七 功能需求

### 数据清洗与自愈

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR 01 | 系统支持在一个月度批次内上传生产、物资、财务和市场的多个 CSV 或 XLSX 文件。 | 批次显示文件、部门、月份、上传人、时间、解析状态和失败原因。 |
| FR 02 | 系统识别字段名拼写差异、日期格式混用、数字与文本混用、列错位、重复行和缺失值。 | 质量报告定位到文件、工作表、行列和问题类型，并可导出。 |
| FR 03 | 系统对可安全修复的问题生成原值、建议值、规则、置信度和影响范围。 | 用户可以逐项或批量接受、拒绝；所有操作写入日志。 |
| FR 04 | 系统不得自动填补关键金额、客户、SKU 或审批字段。 | 此类缺失值始终进入人工确认队列，未确认时下游结果标记为不完整。 |
| FR 05 | 系统按月补齐时间序列并统一年月、币种、单位和数值格式。 | 补齐行与原始行可区分；币种或单位换算必须记录使用的规则和版本。 |
| FR 06 | 系统保存原始文件、标准化结果和差异记录。 | 任意结果可追溯到原始文件与具体单元格。 |

### 颗粒度与语义对齐

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR 07 | 系统维护统一实体目录，包括 SKU、原材料、客户、财务科目、工厂或产线。 | 每个实体具有内部唯一标识、别名、来源系统和有效期。 |
| FR 08 | 系统支持 SKU 与原材料、财务科目、产能耗能指标的多对多映射。 | 映射可以设置生效月份、失效月份、分摊比例和规则说明。 |
| FR 09 | 系统统一日、周、月数据到月度分析粒度，同时保留原始时间粒度。 | 聚合方式对每个指标可配置，并显示求和、平均、期末值或其他口径。 |
| FR 10 | 语义匹配结果显示候选项、匹配理由和置信度。 | 低于阈值的映射不能自动发布；人工确认后形成新版本。 |
| FR 11 | 映射变更不得静默重算已发布批次。 | 系统提示受影响月份，用户选择重算并生成新的结果版本。 |

### 多视角研判与风险预警

| 编号 | 视角 | 需求与输出 |
| --- | --- | --- |
| FR 12 | 生产 | 展示客户订单趋势、产能利用、耗能效率、产能缺口和可能的交付冲突。 |
| FR 13 | 财务 | 识别项目毛利或贡献为负、账期延长、逾期或坏账风险，并列出计算依据。 |
| FR 14 | 物资 | 展示原材料价格趋势、采购成本波动、异常供应成本和对 SKU 成本的影响。 |
| FR 15 | 市场 | 结合客户分层、产能约束、成本和风险给出维护策略建议；建议需显示触发条件。 |
| FR 16 | 公共 | 每条预警包含对象、月份、等级、指标现值、比较基线、阈值、影响、证据和建议动作。 |
| FR 17 | 公共 | 用户可以确认、驳回、指派、备注和关闭预警；状态变化保留操作者和时间。 |

### 汇总与流程输出

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR 18 | 系统按月、季度和年度生成多维 Master Table。 | 表内至少支持月份、SKU、客户、原材料、财务科目、产能、成本、订单和风险维度。 |
| FR 19 | 系统提供按角色过滤的汇总看板。 | 看板指标可下钻到标准化记录、映射规则和原始证据。 |
| FR 20 | 系统生成风险预警报告和审批卡片。 | 报告包含数据范围、缺失项、结论、证据、建议动作、审批人和审批状态。 |
| FR 21 | 系统支持导出 XLSX 和 PDF。 | 导出文件显示数据版本、生成时间和筛选条件，结果与页面一致。 |

### 动态报价模拟

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR 22 | 市场人员选择客户、SKU、数量、目标交期、报价币种和账期后创建模拟方案。 | 系统拒绝缺少成本、产能或汇率依据的正式提交，但允许保存不完整草稿。 |
| FR 23 | 系统联动原材料价格、单位成本、产能约束和客户风险，计算不同价格与账期组合。 | 每个结果显示收入、成本、毛利、产能占用、交付风险和账期风险。 |
| FR 24 | 系统输出建议报价区间和账期选项。 | 建议同时列出采用的输入、规则、限制和敏感因素，不只给出单一数字。 |
| FR 25 | 用户可以比较至少三个方案并提交审批。 | 审批人可以批准、驳回或要求修改；未经批准不得标记为可对外使用。 |
| FR 26 | 首版不自动发送报价。 | 页面和导出流程均需用户确认，系统不调用客户沟通渠道。 |

## 九 核心数据模型

| 对象 | 建议关键字段 | 说明 |
| --- | --- | --- |
| 导入批次 | 批次编号、月份、部门、文件、版本、状态 | 一批次可以包含多个部门文件 |
| 标准化记录 | 来源定位、实体标识、指标、值、单位、币种、月份 | 保留原值、标准值和修复状态 |
| 实体目录 | 实体编号、类型、名称、别名、来源、有效期 | 类型包括 SKU、原材料、客户、科目和产能对象 |
| 映射关系 | 源对象、目标对象、比例、规则、置信度、版本 | 支持多对多和按月生效 |
| 风险事件 | 对象、月份、等级、指标、基线、阈值、证据、状态 | 必须能回溯到记录和规则 |
| 报价方案 | 客户、SKU、数量、交期、价格、成本、毛利、账期、审批 | 保存输入快照和计算版本 |

## 十 规则置信度与人工确认

系统必须区分确定性转换、建议性修复和业务判断。确定性转换可以自动执行，例如统一日期显示格式；建议性修复需要显示置信度和影响；涉及金额、实体合并、信用、产能承诺或报价的结果必须由授权人员确认。

| 处理类型 | 默认行为 | 发布条件 |
| --- | --- | --- |
| 格式标准化 | 自动执行并记录差异 | 规则测试通过 |
| 高置信度拼写或别名匹配 | 可批量建议 | 数据管理员确认或预先批准规则 |
| 缺失值补全 | 仅生成建议 | 确认补全依据；关键字段禁止自动补全 |
| 实体合并和跨部门映射 | 进入映射队列 | 数据负责人确认并发布版本 |
| 风险结论 | 生成预警和证据 | 业务人员确认状态，不改写原始事实 |
| 报价建议 | 生成可比较方案 | 授权审批后才能导出为正式方案 |

## 十一 权限与审计

| 角色 | 读取权限 | 操作权限 |
| --- | --- | --- |
| 平台管理员 | 全局配置和运行状态 | 管理用户、部门、字典和系统配置；不能替代业务审批 |
| 数据管理员 | 授权部门的文件、质量问题和映射 | 确认修复、维护映射、发布数据版本 |
| 部门用户 | 本部门及授权的跨部门汇总 | 查看分析、处理预警、补充说明 |
| 市场用户 | 授权客户、SKU、成本区间和产能状态 | 创建报价模拟并提交审批 |
| 审批人员 | 审批事项及完整证据 | 批准、驳回、要求修改 |
| 审计人员 | 只读访问日志、规则和版本 | 导出审计记录 |

- 所有导入、修复、映射、规则变更、预警处理、模拟和审批操作必须记录用户、时间、前后值和版本。
- 财务数据、客户信用信息和报价数据按最小权限开放；导出行为写入审计日志。
- 系统展示 Agent 结论时必须同时展示证据、规则或数据来源，不允许只显示不可解释的结论。

## 十二 非功能需求

| 类别 | 建议要求 | 验证方法 |
| --- | --- | --- |
| 性能 | 单批次四部门合计 20 万行以内，十分钟内完成解析、质量检查和标准化 | 使用脱敏样例做基准测试，数据量待确认 |
| 可靠性 | 批次任务支持断点重试，同一文件和版本重复提交不得生成重复记录 | 故障注入和幂等测试 |
| 可追溯 | 所有汇总指标和预警均可下钻到来源文件、单元格、规则和映射版本 | 随机抽查输出并反向追溯 |
| 安全 | 传输和存储加密，角色权限、数据范围和导出权限分离 | 权限矩阵、渗透测试和日志审计 |
| 可解释 | 自动修复、映射、预警和报价建议显示原因、输入和置信度 | 逐类检查页面和导出内容 |
| 可维护 | 指标、阈值、映射和审批流通过配置管理并保留版本 | 变更配置后验证新旧批次隔离 |

## 十三 首版验收标准

1. 用四个部门各至少一个真实脱敏文件完成同一月度批次的上传、解析、清洗、确认和发布。
2. 系统能够识别预先定义的拼写、格式、错位、重复和缺失值测试用例，并生成可追溯的修复记录。
3. 至少完成 SKU 到原材料、财务科目和产能耗能对象的映射，并能从汇总指标下钻到来源。
4. 四类部门视图各产生至少一个基于明确规则的指标或预警，结果显示现值、基线、阈值和证据。
5. 系统生成月度 Master Table、风险报告和审批卡片，导出值与页面值一致。
6. 报价模拟能够比较三个方案，并在缺失成本、产能或审批时阻止正式导出。
7. 不同角色只能访问授权数据；关键操作和导出可以从审计日志中复原。

## 十四 成功指标

以下指标为首轮试点建议值，需在取得真实文件和现有流程基线后确认。

| 指标 | 建议目标 | 计算方式 |
| --- | --- | --- |
| 批次成功率 | 不低于 95% | 成功发布批次除以上传批次 |
| 实体映射覆盖率 | 不低于 95% | 已确认映射记录除以需要映射记录 |
| 关键结果可追溯率 | 100% | 可回溯至来源与规则的抽检结果除以抽检总数 |
| 月度整理时间 | 较当前流程减少 50% | 从收齐文件到发布结果的人工耗时对比 |
| 高风险事项闭环率 | 不低于 90% | 在约定期限内关闭或升级的高风险事项占比 |
| 报价审批退回率 | 持续监测不设首轮硬目标 | 因数据缺失或口径错误被退回的方案占比 |

## 十六 主要风险

| 风险 | 影响 | 应对方案 |
| --- | --- | --- |
| 跨部门口径未统一 | 同名指标产生不同结论 | 先冻结首版指标字典；所有规则版本化；分歧由指定数据负责人裁决 |
| 缺失值被错误补全 | 财务和报价结果失真 | 关键字段禁止自动补全；显示依据和置信度；下游结果标记完整性 |
| 实体误合并 | 成本、订单和产能关联错误 | 低置信度进入人工队列；映射变更可回滚；已发布批次不静默重算 |
| Agent 结论缺乏解释 | 业务人员无法审批或信任 | 每条结论绑定现值、基线、阈值、来源和规则 |
| 报价建议越权使用 | 对外承诺错误价格、账期或交期 | 首版仅试算；审批后才能正式导出；禁止自动外发 |
| 数据权限过宽 | 泄露财务、客户和报价信息 | 字段和行级授权；最小权限；导出审计和定期复核 |

## 十七 待确认问题

1. 首版覆盖哪些工厂、业务线、客户区域和币种。
2. 四部门每月文件数量、最大行数、模板稳定性和交付时间。
3. SKU、原材料、财务科目和产能耗能的主数据负责人分别是谁。
4. 订单趋势、产能充足度、耗能效率、潜亏、坏账、价格波动和客户分层的具体公式与阈值。
5. 缺失值补全、单位换算、币种换算和成本分摊的批准规则。
6. 现有 ERP、MES、财务、CRM 或采购系统是否需要读取接口，以及接口频率。
7. 风险等级、处理时限、责任人和升级路径。
8. 报价模拟的最低毛利、产能预留、信用额度、账期上限和审批链。
9. 数据保留期限、脱敏要求、跨部门可见范围和导出限制。
