# 报价声明与文本证据边界

本设计先于实现写定。报价与月度对账并列，共用声明式算术、SourceRef 和官方 DSH Web；真实输入格式、正式报价模板及部门负责人等待业务样板确认。实现范围对应 [任务书](20-quotation-brief.md) 的样板前阶段，实测与费用只记 [状态文档](00-status.md)。

## 自由文本先抽取，再推理

原始合同、客户会话和明细表留在受控存储，不能作为报价工具参数或整份注入上下文。未来适配器先识别文件结构与定位，按人工字典的封闭候选集提取付款条件、数量、单价、交期等事实。文件格式、分段及解析方法等待样板，不在本轮假定。

适配器的内部交接对象是结构化事实集：声明字段标识、规范值、声明单位、抽取状态及 SourceRef。这不是客户上传格式，也不是允许浏览器或模型自证真实的数据接口。本轮只用合成事实验证；不开放自由文本上传或“用户提供 JSON 就算抽取成功”的入口。

沿用 SourceRef，兼容增加文本定位：原文件名称、内容摘要、页或段、有限原文片段。文本引用不伪造表格行列。后续抽取器必须验证片段确实属于对应原件，保留值规范化的依据；只有带引用并不意味着抽取正确。本轮验证引用完整性和绑定关系，不能声称已经实现原文语义核验。

抽取不完整、候选冲突、单位不符、来源缺失、原件版本冲突或超出容量时明确拒绝；未知输入不能自动创造字典条目。不用置信度替代缺失证据，不从采购合同臆测完整生产成本，也不从客户自述推断付款历史。

付款和交付条款的触发点、条件与例外必须保留；不能把条件性条款压成一个天数。样板阶段若声明不能表达原意就拒绝，不套用本合成案例的天数示例。

推理层只得到有界的结构化结果、计算公式、出处样本及真实引用计数。字段、公式深度、事实与片段长度均有限制；不能用“大文件被截断”冒充“完整抽取完成”。原文片段仍是非可信数据，不改变工具权限。报价算数不调用模型。

## 声明与算术

新增独立合成示例字典的 quotation 段，沿用 business_review 的 inputs、roles、metrics、checks、责任人与公式结构。真实字段名、单位、成本构成、利润规则、阈值和决策责任只在人工声明中出现。示例用于证明执行契约，不是已获业务批准的正式报价政策，也不默认装载为生产字典。

共享 business.expression 扩展为可读取已验证结构化事实与同一契约中已声明的指标引用。继续使用封闭运算符，不 eval、不猜列、不创建报价专用价格算法。以 Decimal 求成本及价格，币种不隐式转换，舍入方式由声明明确指定；金额序列化为十进制字符串，避免经浮点数失真。

数值字段必须依赖实际输入证据；纯常量报价不能通过。政策系数是字典声明，不冒充合同事实：同时提供冻结字典的指纹与声明位置，数据出处仍沿用 SourceRef。输入版本和契约指纹绑定草稿，后续样板阶段接入已有不可变批次存储，不能改变已保存批次的月度含义。

## 拒绝与批准边界

先验证全部必需输入，聚合返回缺失项，特别是成本、可用产能和付款历史。拒绝包含稳定原因码、声明字段或检查标识、可读名称、补充证据或决定的负责人；拒绝结果不夹带半成品价格。公式循环、除零、非有限数、未声明指标、缺少责任定义也拒绝。

产能或付款历史超过声明的关注阈值时依声明阻止出数；阈值不是业务批准。成功只生成内部草稿，不代表已批准、已外发或系统完成业务动作。外发入口本轮不提供；后续接现有官方审批、回执和理由通道，不能新增第二套审批。

## 原生界面

界面按用户提供的 NotebookLM 截图定制整个原生工作面：左侧 Sources 保存实际上传文件，中间始终保留 DSH 的原生会话、输入框、轨迹及审批，右侧 Studio 上方为可用工具，下方为持久化产物列表。点击来源或报告在 Studio 预览，也可显式展开阅读；报价声明作为工具预览，不能混进已上传来源或已生成报价。

实现保留官方 AppFrame 及全部槽与状态存储，使用官方 shell.overlay 增加两侧面板，使用宿主公开的 data-slot 样式锚点调整外层几何和主题。直接覆盖 root 会遮蔽原生会话，故不替换根注册、不复制宿主私有组件、不移动原生 DOM。会话与设置收纳为原生导航抽屉；顶栏“新建笔记本”使用官方 sessions.create 创建独立会话并清空当前来源选择，区别于宿主“新建会话”复用空会话的既定语义；空会话可以直接打开 Studio 中的报价声明，不依赖被宿主隐藏的会话页签。月度数据工作区与业务状态页保留，不新增报价会话页签。

参考 better-sidebar 的预览与聊天并存交互，但本轮没有引入其终端、编辑器、侧聊、任意路径读取或其它插件代码。使用本项目受鉴权的批次只读接口足以预览已有 CSV 与单工作表 XLSX；报价原件的格式仍待样板，不新增假定的解析器。

上传时在独立的浏览器来源存储中保留清洗前的表格解析视图，以及文件名、工作表与原件内容摘要；来源清单另存元数据，打开列表不加载整批明细。来源正文不加入 BatchSnapshot，也不加入模型工具返回。只读预览按批次、部门与页码定位；旧批次未保存原件时明确不可预览，不用清洗结果替代。Studio 报告列表只读取实际保存的报告身份；预览沿用原 BusinessReview 及证据组件。切换批次、会话和预览时取消旧请求，避免残留报告与来源串批。

中英文标签、深浅主题、窄屏侧面板、键盘打开与关闭、分页原件、原生输入框身份、父子会话导航和审批都纳入隔离浏览器回归。截图归档遵循保留策略；所有实测数字仅记录在状态文档。

## 笔记本生命周期与状态归属

笔记本创建时通过官方 workspaceId 归入 BridgeFlow 工作区，保存时确认原生工作区成员关系，原生输入框无需再手动选目录。笔记本复用原生会话身份、标题与列表，插件只记录名称、用途、批次和预览位置。用途可选月度对账、报价或综合工作；右侧业务状态与原生状态页随用途调整，不能把报价配置就绪显示成已完成报价。重复点击工具保持打开和选中，来源、工作室及原生导航按钮反映实际展开状态。栏宽支持拖动、键盘调整与重置，仅布局偏好保存在浏览器。

显式保存等待原生标题落盘及官方 storage-domain 写入完成，成功后才显示已保存。新建、退出或从笔记本列表切换时，有名称、用途或来源修改则提示保存、放弃或取消；未修改的空笔记本无需多一次确认。放弃仅丢弃笔记本编辑，不删除宿主已记录的对话、上传文件或报告。原生会话抽屉仍保留宿主切换语义；同一页面中的临时笔记本编辑保留为草稿，不冒充已落盘内容。

保存失败保留当前页面与输入并提供重试。笔记本列表使用原生普通会话目录，包含已经命名但尚未发消息的笔记本，排除部门子会话。恢复使用服务器保存的书签；浏览器刷新与完整宿主重启都在回归范围内。原生会话事件持续保存，笔记本不是另一套聊天数据库。

示例入口明确导入合成的部门数据，走现有清洗与主表计算，冻结示例字典而不改变部署中的字典。来源可预览，规则主表出现在产物栏；报告只有实际研判保存后才出现。示例导入不提交模型请求，发起研判仍是用户明确点击的动作。报价真实样板未到，不用合成 CSV 充当合同解析演示。

## 原生日志与插件元数据

锁定版本的 Session.append 不能为下游自定义事件设置可忽略标记，原生冷读取器会拒绝未知的必需事件。因此不向会话日志追加自定义笔记本、研判或审批备注事件：笔记本书签与拒绝备注保存在官方 storage-domain，研判状态投影来自实际原生工具调用及结果；拒绝理由同时进入原生工具拒绝结果。备注按会话和调用身份绑定，存储键使用组合身份的摘要以符合官方逐记录存储约束。

旧的 bridgeflow/review 与 bridgeflow/approval-note 仅是信息性元数据。若历史日志因此无法冷读，停机后可用 scripts/repair_session_metadata.py 先检查，再显式应用兼容标记；工具保存原始字节备份，只将已知信息事件标为可忽略，不改领域数据、事件内容、顺序或模型用量，不触碰其它未知必需事件。正常启动不自动改写或剪裁用户日志。

## 验收边界

合成事实加声明可生成带证据的草稿；移除任何必需依据、改错单位、损坏出处或制造公式错误必须拒绝。字段整体重命名后仅更新声明与合成事实即可继续运行。月度对账用例照常通过。浏览器只验证实际可用的契约查看和布局，不把空页面算作合同抽取或报价外发已交付。

数据工作区弹窗单独注册在官方 shell.overlay，侧栏仅注册打开入口。不得把会使页面进入模态的组件置于可隐藏的侧栏祖先下；功能验收必须确认弹窗真实可见、关闭后能继续操作，不能以无 JavaScript 异常代替。来源信息应解释文件与批次身份，单页说明无需翻页，多页验证双向内容变化。
