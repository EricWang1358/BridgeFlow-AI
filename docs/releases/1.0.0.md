# BridgeFlow AI 1.0.0

BridgeFlow AI 首个公开正式版本，基于官方 DeepSeek Harness，将生产、物资、财务、市场的月度表格整理为可追溯的跨部门主表，并支持四部门研判、人工审批与业务流转。

## 本版包含

- 表格导入、字段匹配、清洗、隔离行处理、主表合并、指标核对与来源追溯。
- 四部门子代理研判、证据校验、月度结论、Word 报告与工作簿导出。
- 字典起草、逐条审核、版本发布，以及写入前的原生人工审批。
- 材料立项、流程图、候选评分、MVP 决策与填报交接工作流。
- 笔记本、总览、业务状态指引、决策记录，以及审批写入后的工作室自动刷新。
- 中英文界面与使用说明、合成示例、引导任务、英文演示数据和演示录制脚本。
- 飞书登录门户、独立访客演示模式、模型访问闸门与部署脚本。

## 安装与使用

```bash
git clone --branch v1.0.0 https://github.com/EricWang1358/BridgeFlow-AI.git
cd BridgeFlow-AI
```

继续按照 [中文安装说明](https://github.com/EricWang1358/BridgeFlow-AI/blob/v1.0.0/README.zh.md) 或 [English setup guide](https://github.com/EricWang1358/BridgeFlow-AI/blob/v1.0.0/README.md) 安装依赖与启动服务。

使用步骤见 [中文使用说明](https://github.com/EricWang1358/BridgeFlow-AI/blob/v1.0.0/docs/user-guide.zh.md) / [English user guide](https://github.com/EricWang1358/BridgeFlow-AI/blob/v1.0.0/docs/user-guide.en.md)。DeepSeek Harness 继续锁定为 `0.1.2-rc.1`（Python SDK 为 `0.1.2rc1`）。

## 版本边界

这是以合成数据演示业务流程的黑客松项目。AI 研判需要配置模型服务并产生调用费用；访客入口和飞书登录需要相应服务器配置。真实企业数据验收、完整多租户隔离、大规模数据能力及报价对外签发仍有未完成项。实测证据和已知限制见 [项目状态](https://github.com/EricWang1358/BridgeFlow-AI/blob/v1.0.0/docs/00-status.md)。

## English

The first public release of BridgeFlow AI brings together traceable spreadsheet consolidation, four-department AI reviews, human approvals, discovery and handoff workflows, bilingual guides, synthetic samples, and guest-demo deployment support on the official DeepSeek Harness.

This is a hackathon business demonstration. AI reviews require a configured model service and incur usage costs. Enterprise acceptance, full tenant isolation, large-scale data handling, and external quotation issuance remain incomplete; see the linked project status for evidence and limitations.
